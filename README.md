# 楚河汉界

中国象棋网页游戏：红黑对弈、规则完整、三档电脑棋力。

## 功能

- 九路十行棋盘，楚河汉界、九宫、炮位与兵位标记
- 完整规则：蹩马腿、塞象眼、炮隔子打、将帅对面、将死 / 困毙
- 电脑三档：**简单**、**中等**、**困难**（置换表、开局库、α-β 搜索）
- 执红或执黑，悔棋、提示、认输
- 中文记谱（如「炮二平五」）
- 战绩与残局自动保存（浏览器本地）

## 本地运行

需要 Node.js 22+。

```bash
npm install
npm run dev
```

浏览器打开终端里提示的地址即可下棋。

```bash
npm run typecheck
npm run build
```

## 难度

| 档位 | 风格 |
|------|------|
| 简单 | 入门练习，电脑偶尔漏着 |
| 中等 | 开局有谱，能攻能守 |
| 困难 | 置换表深搜，会夺子反击 |
